# Feature: Shopping Cart

When a user adds a food item to the cart:
- The selected food item should appear in the cart.
- The cart quantity should increase correctly.
- The total price should equal the sum of each item's price multiplied by its quantity.
- Increasing the quantity should update the total price.
- Removing an item should remove it from the cart.
- The cart should not display an incorrect total when the quantity changes.

Generate positive, negative, and boundary test scenarios where applicable.

Use the actual UI and behavior of the Food Delivery Website. Do not invent selectors, routes, API responses, or features. Identify any assumptions that cannot be verified from the requirement.
